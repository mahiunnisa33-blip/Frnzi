# FRNZI
Meet. Talk. Connect.

This is a Flutter UI prototype for the FRNZI social/language conversation app.

## Run
1. Install Flutter.
2. Create/open this project.
3. Run `flutter pub get`
4. Run `flutter run`

This prototype includes:
- Welcome/onboarding
- Language selection
- Interest selection
- Home/discovery
- Chats
- One-to-one chat UI
- Auto-translate placeholder
- Profile/settings UI

The chat data is local demo data. A production version needs a backend, authentication, database, moderation/reporting, push notifications, and secure real-time messaging.
